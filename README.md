# Python Calculator

A simple command-line calculator built with Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection
- Interactive command-line interface

## How to Run

Make sure Python is installed, then run:

```bash
python calculator.py
